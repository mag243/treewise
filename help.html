Names, templates and git.

Treewise proposes names for your files in the pattern a folder already follows, makes a structure of folders again from a template, and on the Mac shows what changed in a git repository.

Parts marked Mac only are not in the iPad and iPhone app yet.

Suggested names

Treewise reads the names in a folder, finds the pattern they follow, and proposes a name in it for each file that does not fit. Nothing is renamed until you approve, and Undo turns it back.

Text in the old name is kept: Acme_invoice.pdf becomes 2026.03.14 Taxes - Acme invoice.pdf. A name that nearly fits is offered written right: Taxs becomes Taxes.

What Treewise recognises

RecognisedRule
A patternAt least 3 of the folder’s files follow it, and more than half of them
A dateAt the start of a name: 2026.03.14 2026-03-14 20260314 14.03.2026 14-03-2026; on the Mac anywhere in it, also as 14 March 2026, 3 mrt 2026 or März 2026 Mac only
Shared textText all names have stays as it is, such as Taxes -
A numberA word with a number after it, such as Scan 12; on the Mac also years, quarters and months that run Mac only
The folder’s nameText that is the folder’s name becomes {folder}
Too few namesRename with Suggestions uses your default pattern; on the Mac, the same folder of the year before may give the pattern Mac only

The date in a proposal is the date a photo was taken or a PDF was made, when the file holds one, otherwise the older of its created and modified dates; the overview marks it, so you can check it. The extension is never part of a pattern. Everything runs on your device, without the internet.

Pattern fields

Change a pattern in the overview with Change, or keep it in Settings › Names. Text outside braces and brackets is written as it stands.

Add your own in Settings › Names. When you change one, each folder that uses it asks whether to take the new version. A colon cannot be in a name, and { } [ ] < > always belong to the pattern; a mistake is named, such as “Every [ needs its ]”.

Folder templates

A template is a folder’s structure: its folders at every depth, without their files.

  1. Save

    On a folder: Folder Structure › Save as Template…

  2. Change

    Settings › Templates: rename, add, move or delete folders, and put fields in names with Insert Field.

  3. Make

    On the folder to hold them: Folder Structure › New Folders from Template. Only missing folders are made; Undo removes them.

A repeating folder gets a copy of everything inside it, and cannot sit inside another. On the Mac, saving a template turns a year in the names into {year} and twelve month folders into one Each Month by itself; on the iPad and iPhone, use Insert Field.

Git status Mac only

In a folder of a git repository, every file and folder shows its state on its icon, as the Terminal’s git status would tell it. Treewise only reads your repositories: it never stages, commits or changes them.

On the iconIn the Git columnMeans
A dotModifiedChanged since the last commit, or for a folder: something in it changed or was deleted
A ringNewNot in the repository yet; a folder that is new as a whole
A diamondConflictA merge left it in conflict; a folder holding one shows it first, so you can follow the diamonds down the tree
DimmedIgnoredLeft out by .gitignore, such as a build folder

The folders in the sidebar show the same badges, and a repository’s top folder has a small git mark at the end of its row. The Git column is off at first: right-click a column heading and choose Git. Sorting on it puts conflicts first, then the other changes.

Treewise uses the git of Apple’s Command Line Tools or of Homebrew. Without one, Settings › General offers Install…, which asks macOS to install the Command Line Tools; nothing is asked before you click it. Show Git status in the same place turns it all off.
